# Fingerprint Voting System

A web-based voting system developed using PHP, MySQL, HTML and CSS. The project provides modules for voter registration, fingerprint-based authentication, voting, and election official management.

## Features

- Voter registration
- Fingerprint authentication component
- Secure voter authentication workflow
- Online voting interface
- Election official registration
- Election official login
- Election official dashboard
- Vote management
- Vote result export
- MySQL/MariaDB database integration

## Technologies Used

- PHP
- MySQL / MariaDB
- HTML
- CSS
- XAMPP / WAMP
- phpMyAdmin

## Project Modules

### Voter Module

- Register as a voter
- Authenticate the voter
- Access the voting page
- Cast a vote

### Election Official Module

- Election official registration
- Election official login
- Manage voting-related information
- View and export election results
